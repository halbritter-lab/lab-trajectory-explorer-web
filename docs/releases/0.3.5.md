# v0.3.5 — All cohort model presets with the demo, plainer interface text

The demo data can now show every cohort model preset. Subgroup comparison could
not fit any group before: with 14 patients every split stayed below the
ten-patient minimum, and Group interaction had seven complete cases. Fourteen
synthetic patients (15-28) and attributes for patients 1, 2, 4 and 6 give
cohort A 12 and cohort B 10 patients and both sexes at least 12; 25 patients
have eGFR. Golden fixtures are unchanged.

With a grouping, the studio lists before fitting how many patients with enough
measurement times each group contributes. When no group reaches the minimum but
the whole cohort does, it says so in one sentence and the action reads "Fit
whole cohort only"; other validation reasons are still listed per group.

Interface text no longer strings items together with middle dots: counts use
commas, card titles "1.", additions brackets, chart titles a colon, and the
footer and export notes are sentences. Slope-quality labels read "n < 3,
uncertain slope" and "Follow-up < 1 year, uncertain slope". A table cell
without dated measurements shows one line instead of five.

Numerical calculations, data formats and exported values are unchanged. The
header displays v0.3.5.

The owner asked on 2026-10-13 to shorten empty cells and then release this
scope. Research/user acceptance remains open as documented for v0.3.0; this
release does not claim clinical acceptance.

Local verification: 912 unit/component tests, the production build and all 46
Chromium checks passed. Real WebR fits on the demo (eGFR, default settings):
Standard −4.71 ml/min/1,73m²/yr; Subgroup by cohort A −4.32, B −8.18; by sex m
−4.91, w −4.51; Demographic adjustment −4.77; Group interaction −3.81; none
singular. An independent review found one important and several minor issues,
all fixed before release. Actual release-triggered deployment evidence will be
added to the GitHub Release after publication.

## User workflows

- The workspace replaces the former interface at `/`: Data prepares imports,
  Trajectories compares patient courses, and Cohort models fits associations
  and conditional trend projections. Old `/workspace.html` links redirect.
  Analysis presets, independent parameter settings, patient browsing, overlay
  controls, responsive tables, and adjustable chart sizes support that flow.
- CSV values and IDs retain their original text; stricter date, value and
  header handling reports rejected rows and demographic conflicts. Manual age
  now advances over time; resolved demographics are shared across analyses.
  eGFR derivation can therefore change values for conflicting or repeated ages.
- Workbook exports include analysis and endpoint provenance; patient ZIP
  bundles and SVG/PNG chart exports cover workspace and model previews.
  Opt-in saving retains source data, events, attributes, manual demographics
  and derivation settings for seven days, with stale-tab and deletion guards.
  **Former-interface saved data is deleted at startup**, with a one-time notice.
  Valid earlier workspace copies migrate to the app's own IndexedDB database;
  analysis/view settings and fitted models reset on resumption.
- Cohort models support configurable covariates, reference categories and
  level/slope effects, with editable profile projections and custom thresholds.
  Models now use the parameter's Trajectories preparation settings. Invalid
  or singular fits withhold projections; fitting needs enough longitudinal
  patients. Fit controls explain unavailable configurations, and grouped fits
  report eligible and skipped units. Patient-opening targets are at least
  44 by 44 CSS pixels, including narrow touch-enabled browser coverage.

## Owner-approved methods

The [decision record](../remaining-method-decisions.md) and
[implemented algorithms](../method-algorithms.md) describe the approved changes
and their boundaries. Methods-page wording was reviewed by the owner.

- Observed G4/G5 and confirmed 40%/57% decline endpoints use explicit confirmation
  rules and report recovery separately. Kidney replacement therapy stops
  endpoint evaluation and individual G5 prediction; projections also require
  adequate follow-up, fit uncertainty and a bounded horizon.
- Bounded/censored measurements stay out of fits, endpoint evaluation, AKI
  detection and cohort models. Non-exact creatinine retains that status in
  derived eGFR. Non-positive creatinine and dialysis intervals do not produce
  AKI episodes. eGFR recognition uses accepted mL/min/1.73 m² unit spellings;
  bare ml/min does not receive these endpoints.
- Theil–Sen estimation and its confidence bounds, rolling-window visualization,
  cohort preparation and projected-age handling have explicit contracts and
  regression evidence. Several changes alter numerical results or clinical
  classifications; existing golden fixtures remain regression references,
  while the Python package no longer binds all future method choices.

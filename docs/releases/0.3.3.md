# v0.3.3 — Structured help and reference

Methods now opens a short workflow guide and nine focused topics. Desktop users
have a sidebar; narrow screens have a collapsible topic menu. Section links
reveal calculation details, and the current topic can be bookmarked or shared.
Contextual links from Data, analysis settings, endpoint details and cohort
models open the corresponding explanation. Model choices, status meanings and
export contents are easier to scan in tables.

The follow-up UX review added reachable workspace return actions, sticky mobile
topic controls, direct guide actions and independently collapsible calculation
groups. Troubleshooting shortcuts precede onboarding. Reference tables use
larger text and readable columns inside named keyboard-accessible scroll regions;
question shortcuts and detail controls have touch targets of at least 44px.

Help navigation retains mounted workspace state, including patient detail and
the overlay return view. The Methods button, browser history, repeated section
links and keyboard skip link keep the displayed topic and URL consistent.

Scientific rules, examples and sources are preserved. Numerical calculations,
data formats, exports and dependencies are unchanged. The header displays
v0.3.3.

The owner requested a further UX review, fixes, commit, push and deployment on
2026-10-11. This authorizes publication of the structured-help scope and its UX
fixes. Research/user acceptance remains open as documented for v0.3.0; this
release does not claim clinical acceptance or a fresh real-WebR smoke run.

Local verification: 892 unit/component tests, the production build and all 46
Chromium checks against that build passed. Two independent UX assessments and
a bounded confirmation found no remaining blocking UX issues. The initial
code review and navigation regression fixes are also recorded with the changes.
Actual release-triggered deployment evidence will be added to the GitHub Release
after publication.

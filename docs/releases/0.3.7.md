# v0.3.7 — Direct trajectory controls and attribute columns

The trajectory interface reviewed in the interactive demo now ships in the real
application. Patient attributes can appear as ordinary columns without changing
the order; their headers provide sorting and optional grouping. Content-based
widths keep short attributes narrow. S/M/L chart sizes are directly available.

Each parameter has separate controls for calculating its trend and displaying
the fitted line, plus a method selector and contextual settings. Analysis starts
disabled. Hiding a line retains calculated results; disabling analysis uses the
existing no-fit calculation path. Shared defaults contain general presets, and
specialist presets are assigned explicitly per parameter in both Trajectories
and Cohort models. Domain-specific configuration uses optional UI adapters.

Minimal cells reduce repeated text, explanations are available through icon
tooltips, and AKI keeps its short pill. Compact selection dialogs retain whole
row activation and larger touch targets. Escape dismisses dialogs and menus and
returns focus. Switching a derived parameter preserves its trend activation,
line visibility and independent settings. Numeric estimators, clinical thresholds
and imported values are unchanged.

The owner accepted the iterated interface and explicitly requested merge and
deployment on 2026-10-15. This authorizes publication of this scope; it does not
establish research, clinical or representative-user validation.

Deployment evidence is recorded on the GitHub Release page after publication.

Local verification: 929 unit/component tests, the production build and all 51
Chromium browser tests passed. These cover imports, exports and provenance,
trend calculation versus visibility, parameter preparation scope, history,
derived-parameter identity, responsive layouts, touch targets, and modal cleanup
on navigation and resize. Help-copy changes also passed their eight focused
component tests. Independent code review identified and verified the integration
fixes before merge. No files under `src/core/` changed.
